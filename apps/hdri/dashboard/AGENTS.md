## Manifest-only consumption (RFC-0115)

The dashboard consumes period manifest files (`PeriodManifest`) generated by the observatory release pipeline. It does **not** read vault shards, sealed capsules, or raw observation databases directly. The build step loads pre-generated period JSON files via `import.meta.glob` in `src/data/dashboard-data.ts`.

- **Score data source**: existing `src/assets/data/public/periods/<period>/*.json` archive files
- **Availability data source**: `src/assets/data/public/availability/<period>/{public-manifest.json,availability.json,availability.csv}`, installed only after verified publication admission. The loader does not read private previews. It checks manifest hashes/sizes, schema v2, scope, policy binding, four counts, small cells and exact CSV/JSON agreement; candidate/preview statuses fail. These build-time checks are not admission.
- **Codebook**: `codebook-observatory-*.yaml` auto-discovered via glob, highest version wins
- **No direct vault access**: The dashboard never imports `@syrokomskyi/observatory-vault` or reads `.output/db/` databases
- **Build/publication separation**: The Astro build produces static HTML from manifest JSON only; it does not trigger observatory pipeline runs or release operations

## Original publication thresholds and comparison explanation

Q2's original publication threshold is **5**, Q3's is **12**. The retained Q2
manifest was regenerated after privacy hardening and contains 12; do not silently
rewrite it or the sealed archive. `src/data/publication-policy.ts` owns the explicit
display erratum, bound to Q2's exact publication run. The May 30 manifest in git
commit `04488a05d` proves k=5 for that same run/bundle/sample. Index labels and
table provenance must use `publicationThreshold(manifest)`, not read the retained
Q2 metadata as the original policy. Do not apply this correction to future quarters
or new releases. Methodology and Q2 pages visibly disclose the correction.

The methodology, FAQ (including structured data), glossary and quarter archive
explain that Q2/Q3 are descriptive snapshots, not an admitted trend series.
Expanding the collection frame is not inherently incompatible with time comparisons;
freezing the sample does not establish representativeness. No population or matched-
panel trend may be inferred from a raw difference between the published snapshots.
The stricter privacy threshold alone is not a scientific prohibition on comparison.

## CSS convention

- No `<style>` blocks inside `.astro` files. Always use separate CSS files, imported in the frontmatter.
- Route pages → `src/styles/<route>.css` (e.g. `src/styles/glossar.css`)
- Components → `src/styles/<ComponentName>.css` (e.g. `src/styles/term.css`)
- Shared primitives → `src/styles/global.css`

## Popover API (Term component)

- The Term component uses native `popover="auto"` + CSS anchor positioning.
- Do NOT add `display: block` to the base `.term-popover` rule — it overrides the UA `[popover]{display:none}` and makes all popovers visible on page load.
- Only set `display: block` inside `.term-popover:popover-open`.
- Use absolute `px` units (not `rem`) for font sizes inside `:popover-open` to avoid DOM context inheritance in the top layer.

## Slot forwarding pattern

- `BaseLayout` forwards the `header-extra` slot into `SiteHeader`'s `extra` slot for page-specific header rows.
- The `.site-header-extra` element is hidden via `:has(> .container > *)` when the slot is empty.

## Lenis smooth scroll

- All anchor click handling is in `BaseLayout`'s Lenis script.
- Do not add separate `scroll-behavior` CSS.

## Shared modules

- **`src/types.ts`** — all shared TypeScript types (`Summary`, `Maturity`, `DimensionItem`, `SliceItem`, `MatrixItem`, `PeriodManifest`, `Overview`, `ComparisonPoint`). Import from here instead of redefining inline.
- **`src/lib/format.ts`** — all formatting functions (`score`, `count`, `pct`, `weight`, `axisRange`, `barColorClass`, `deltaLabel`, `formatDate`, `reliabilityLabel`, `reliabilityClass`, `percentileTooltip`, `detailGrid`). All use `LOCALE = "de-DE"`. Do not duplicate `Intl.NumberFormat` calls in pages or components.
- **`src/lib/seo.ts`** — centralized `site` URL, `ogImage`, and `publisher()` schema.org object. All pages import from here instead of hardcoding `"https://handwerk-index.org"`.
- **`src/data/dashboard-data.ts`** — data loaders: `loadCurrentPeriod(period)`, `loadCodebook()`, `loadChangelog()`, `readPeriodFile()`. All `import.meta.glob` calls live here, not in pages. `loadCodebook` auto-discovers `codebook-observatory-*.yaml` via glob and picks the highest version — no hardcoded filenames.
- **`src/scripts/tooltip.ts`** — `initTooltips(selector)` for accessible tooltip behavior. Pages call this in a `<script>` tag instead of inlining tooltip logic.
- **`src/components/ComparisonTable.astro`** — reusable comparison table with provenance badge and optional details modes (`"none" | "first" | "all"`). Use for any trend/comparison table with P75, Mittelwert, Delta, N columns.
